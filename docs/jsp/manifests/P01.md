# P01 - account/profile

## Phạm vi

- Chủ trang: Đạt; JSP-DAT-02 (A/D), C nối tiếp ở JSP-DAT-07 / TC01.
- Nguồn đối chiếu: `ui-prototype/pages/account/profile.html`, JS/CSS cùng trang.
- Output: `src/main/webapp/WEB-INF/views/account/profile.jsp`; JS/CSS riêng dưới `src/main/resources/static/`, cùng hậu tố `pages/account/profile`.
- Hiện chỉ chuyển JSP và tương tác giao diện. Chưa tạo Servlet/Controller, cấu hình MVC hoặc API.

## Route và dữ liệu cần bàn giao

- Đề xuất `GET /account/profile`, view `account/profile`; Đại đăng ký mapping khi có nền.
- JSP đặt dưới WEB-INF nên cần Servlet forward hoặc Spring MVC view mapping để mở qua HTTP.
- Không có query nghiệp vụ; owner do server session quyết định. Giữ hash `#ho-so`.
- Model cần cấp: `profile` (id/name/email/phone/bio/avatar), `formErrors` (name/email/phone/bio), `profileInitials`, `profileRoleLabel`, `profileState` (ready/loading/empty/error).
- JSP dùng JSTL/EL, dữ liệu text và input được escape bằng `c:out`. Khi thiếu profile, hiện thông báo chờ tích hợp; không tự chèn dữ liệu giả.

## Layout và assets chờ Đại

- Fragment đề xuất: `/WEB-INF/views/fragments/layout/user-header.jsp` và `/WEB-INF/views/fragments/layout/account-footer.jsp`; chưa có tại snapshot, cần Đại xác nhận và bàn giao.
- Common CSS/assets production cần nằm dưới `/css/` và `/assets/`.
- Thứ tự CSS: tokens, reset, base, utilities, layouts, form/input, feedback/alert, layout/user-header, layout/account-footer, layout/page-header, pages/account/profile.
- Chỉ nạp một script page `/js/pages/account/profile.js`; layout quản lý script shared.
- Không nạp route/fixtures/store/user-header của prototype. Không chỉnh core/shared hoặc nguồn prototype.
- URL JSP dùng `c:url` để giữ context path. Chưa kiểm lại HTTP ở cấu trúc hiện tại vì chưa có mapping/fragments/assets nền.

## Hooks và hành vi giao diện

- Giữ form `.profile-form`, `novalidate`, `data-profile-form`, các ID name/email/phone/bio, display/control/edit/save/cancel/status/avatar/count hooks.
- JS riêng xử lý edit, dirty, validation, bio counter, cancel về snapshot gần nhất và cập nhật DOM.
- Nút lưu dùng submit/form association; JS chặn submit nên không gửi dữ liệu tới endpoint chưa có.
- Lưu chỉ áp dụng trên giao diện và có thông báo rõ chưa lưu hệ thống. Reload lấy dữ liệu do bên cấp model cung cấp lại.
- Bio giới hạn 300 ký tự; giữ xuống dòng khi đọc; lỗi có aria-invalid và focus vào trường đầu tiên sai.
- Khi JavaScript tắt, edit disabled; không mở input để gửi form ngoài ý muốn.
- Header/menu/logout do fragment và module chung phụ trách; private JS chỉ xử lý form hồ sơ.

## C còn chờ

- Đại cấp A01/A02: session/quyền, profile DTO/service/API, editableFields/version/fieldErrors, chính sách đổi email/avatar.
- GET/PATCH `/api/account/profile` mới là đề xuất; chưa tạo endpoint hoặc adapter.
- C phải kiểm owner/401/403, validation/network/version conflict, lưu và đọc server lại sau refresh.
- Avatar hiện dùng initials; hiển thị ảnh và quyền sửa từng field chờ contract.
- Checklist HTTP/direct/refresh/context path/assets/console/responsive chỉ chạy lại sau khi nhận đủ nền.
