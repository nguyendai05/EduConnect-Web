## SQL reset theo yêu cầu

Đã tạo database/00_drop_database_dev.sql, chỉ DROP DATABASE IF EXISTS educonnect_dev theo tên cố định. **Chưa thực thi file DROP.** Vì educonnect_dev hiện trống, có thể bỏ bước DROP và chạy lại file00_create_database.sql; DROP không xử lý 24 bảng đang ở webshop_db.

File reset là thao tác chủ động của người dùng trên development, không nằm trong chuỗi bootstrap thông thường/Flyway. Nếu database đã phát sinh dữ liệu sau thời điểm kiểm này, DROP sẽ xóa dữ liệu đó; đọc metadata/backup trước khi chạy.

## Thứ tự chạy lại đúng

1. Nếu muốn reset, chạy database/00_drop_database_dev.sql; chỉ schema educonnect_dev bị tác động.
2. Chạy database/00_create_database.sql.
3. Ngay trước V1, chạy USE educonnect_dev; SELECT DATABASE(); SHOW FULL TABLES; trong connection/tab hiện tại. Database phải đúng tên và chưa có đối tượng.
4. Workbench Set as Default Schema = educonnect_dev; nó phải in đậm. Chạy full V1, dừng tại lỗi đầu tiên.
5. Khi V1 thành công đủ 51 bảng/4 view, chạy V2 rồi V3 đúng một lần.
6. Nạp database/02_seed_dev.sql nguyên file, rồi database/03_verify.sql.
7. Nếu dùng Spring/Flyway sau đường thủ công, đối chiếu full schema/reference với database thử Flyway và baseline3 theo README trước boot; không bật baselineOnMigrate hoặc viết tay history.

Không thêm IF NOT EXISTS vào mọi CREATE TABLE để bỏ qua lỗi1050: cách đó sẽ che bảng cũ có cấu trúc sai. Không sửa canonical V1 thành USE cố định, không xóa cart_items của webshop_db để tiếp tục V1.
