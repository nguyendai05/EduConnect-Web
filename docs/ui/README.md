# Tài liệu giao diện

Việc xây dựng giao diện bắt đầu từ các giá trị thiết kế dùng chung (design token) và các component có thể tái sử dụng. Bản mẫu của từng trang nên được ghép từ những thành phần này; CSS và xử lý JavaScript riêng của từng tính năng cần được đặt trong các thư mục `pages/` tương ứng.

- [Danh sách component dùng chung](component-inventory.md)
- [Bản đồ các trang giao diện](page-map.md)
